# SUPPORT.md for oss-contribution-finder

## Getting Help

- **Bug Reports:** Open an issue with the `bug` label. Include your Python version, OS, and the query that failed.
- **Feature Requests:** Open an issue with the `enhancement` label describing the feature or platform you want supported.
- **Usage Questions:** Open an issue with the `question` label.

## Community
- GitHub Discussions: Not yet available — use Issues for now.

## Priority Service Levels
| Channel | Response Time |
|---------|--------------|
| Bug reports (labeled `bug`) | Within 7 days |
| Feature requests | Triaged weekly |
| Questions | Best-effort |
